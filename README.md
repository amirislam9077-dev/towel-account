# Al Hasan Towel

Towel order software: Towel PO (weaving program) with quality, Pile / Ground / Weft (Bobbin) / Fancy yarn,
items (Pcs Wt, Size, Qty, Rate / Lbs), shortage and yarn bag requirement, print and Excel.

## Run on your computer

```
npm install
npm run dev
```

Open http://localhost:5174/towel/po

- Web (Vite + React): port 5174
- API (Express): port 4001
- Data is saved in `server/data.json` (created on first start; not in git)
